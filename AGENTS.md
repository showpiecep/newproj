# Правила репозитория

Репозиторий содержит Copier-шаблоны проектов и установщик команды `newproj`.
Правила разработки конкретного проекта живут внутри своего шаблона, например
[templates/fastapi-yaml/AGENTS.md](templates/fastapi-yaml/AGENTS.md), и
относятся к сгенерированному проекту, а не к этому репозиторию.

## Границы

- В `templates/<имя>/` лежит только содержимое будущего проекта. Ни установщик,
  ни CI, ни документация репозитория туда не попадают.
- В корне лежит только инфраструктура распространения: `install.sh`,
  `installer/`, `.github/`, документация репозитория.
- Файлы шаблона рендерятся Jinja (`_templates_suffix: ""`), поэтому любой
  `{{` или `{%` внутри шаблона обязан быть осознанным. Файлы репозитория
  Jinja не обрабатываются.

## Шаблоны

- Один каталог в `templates/` — один шаблон с собственным `copier.yml`.
- Новый шаблон не требует правок установщика или `newproj.zsh`: оба находят
  шаблоны по наличию `copier.yml`.
- Артефакты локальной работы (`config.yaml`, `.venv`, кеши) должны быть в
  `_exclude`, иначе они попадут в сгенерированный проект при генерации из
  рабочей копии.

## Скрипты

- `install.sh` и `installer/build-release.sh` — переносимый POSIX `sh`, без
  расширений bash и zsh.
- `installer/newproj.zsh` — Zsh; функция обязана работать при `zsh -df`.
- Установщик изменяет файлы пользователя, поэтому обязателен порядок
  «сначала все проверки, затем изменения»: любая правка должна сохранять
  проверку контрольной суммы, `zsh -n` перед записью rc-файла, резервную копию
  rc-файла, отказ трогать неуправляемый шаблон и откат при неудачной подмене.
- Управляемый блок в rc-файле ограничен маркерами `# >>> newproj >>>` и
  `# <<< newproj <<<`; повторная установка обязана оставаться идемпотентной.

## Проверка изменений

- После правок установщика запускать `sh installer/test-install.sh` — тест
  работает в изолированном `HOME` и не трогает файлы пользователя.
- После правок шаблона проверять генерацию и быстрые проверки полученного
  проекта: `copier copy templates/<имя> <путь> --trust` и `make check`.
